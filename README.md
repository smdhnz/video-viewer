# ビデオビューア

ローカル動画と動画URL（HLS `.m3u8` 含む）をプレイリストで再生できるシンプルな動画再生アプリです。

## 機能

- 動画ファイルのドラッグ＆ドロップ追加
- 動画URL / HLS URLの追加
- `public.ynjn.jp` 用プロキシ rewrite
- プレイリストの並び替え、選択、削除
- サムネイル・再生時間の自動取得
- 再生 / 一時停止、シーク、音量、ミュート
- フルスクリーン、90度回転
- 前後の動画へ移動、自動で次を再生

## ショートカット

| キー          | 機能                       |
| ------------- | -------------------------- |
| `k`           | 再生 / 一時停止            |
| `Space` + `l` | 1フレーム進む（30fps基準） |
| `Space` + `h` | 1フレーム戻る（30fps基準） |
| `f`           | フルスクリーン             |
| `m`           | ミュート                   |
| `↑` / `↓`     | 音量変更                   |
| `→` / `l`     | 5秒進む                    |
| `←` / `h`     | 5秒戻る                    |
| `r`           | 90度回転                   |
| `n`           | 次の動画                   |
| `p`           | 前の動画                   |

## 開発

```bash
bun install
bun dev
```
